# Video Assets Directory

This directory should contain the following videos for the portfolio:

## Required Videos

1. **intro-video.mp4**
   - Executive introduction video (2-3 minutes)
   - Professional tone, clear audio
   - Recommended: 1920x1080 (1080p), 16:9 aspect ratio
   - Format: MP4 (H.264 codec)

## Optional Speaking Engagement Videos

2. **speaking-panel1.mp4**
   - Video of panel discussion or presentation
   - Recommended: 1920x1080 (1080p), 16:9 aspect ratio
   - Format: MP4 (H.264 codec)

3. **speaking-panel2.mp4**
   - Video of panel discussion or presentation
   - Recommended: 1920x1080 (1080p), 16:9 aspect ratio
   - Format: MP4 (H.264 codec)

## Video Specifications

- **Resolution:** 1920x1080 (1080p) or higher
- **Aspect Ratio:** 16:9
- **Format:** MP4
- **Codec:** H.264 (recommended for broad compatibility)
- **Audio:** Clear, professional quality
- **Bitrate:** 5-10 Mbps for good quality without excessive file size

## Video Best Practices

- Ensure good lighting and audio quality
- Professional attire and setting
- Keep videos concise and focused
- Optimize file size for web delivery (consider compression)
- Test playback in multiple browsers

---

**Note:** Videos will display error messages if not found. The portfolio will still function without videos, but multimedia content enhances the executive presentation.
